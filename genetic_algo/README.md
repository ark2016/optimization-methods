# Восстановление изображения многоугольниками с помощью генетического алгоритма

Лабораторная работа по изучению генетических алгоритмов и особенностей их реализации.

## Задача

Восстановить целевое изображение, используя набор полупрозрачных многоугольников. Генетический алгоритм эволюционирует популяцию «особей» (наборов полигонов), минимизируя попиксельную разницу между нарисованным и целевым изображением.


## Реализованные операторы

### Операторы выбора родителей

| Оператор | Функция | Описание |
|---|---|---|
| Метод рулетки | `roulette_selection` | Вероятность выбора пропорциональна приспособленности особи |
| Турнирный отбор | `tournament_selection` | Из t случайных особей лучшая попадает в промежуточную популяцию |
| Отбор усечением | `truncation_selection` | Упорядочивание по приспособленности, отбор лучших |
| Случайный выбор пары | `random_pair_selection` | Оба родителя выбираются случайно |
| Селективный выбор | `selective_pair_selection` | Родителями могут стать только особи с fitness >= среднего |
| Инбридинг | `inbreeding_selection` | Второй родитель — ближайшая особь (евклидово расстояние) |
| Аутбридинг | `outbreeding_selection` | Второй родитель — самая далёкая особь |

### Операторы рекомбинации (кроссинговера)

| Оператор | Функция | Описание |
|---|---|---|
| Одноточечный | `single_point_crossover` | Одна точка разреза, обмен сегментами |
| N-точечный | `n_point_crossover` | N точек разреза, чередование сегментов |
| Однородный | `uniform_crossover` | Случайная битовая маска определяет источник каждого гена |
| Ограниченный | `restricted_crossover` | Точки разреза только там, где гены родителей различаются |

### Операторы мутаций

| Оператор | Функция | Описание |
|---|---|---|
| Двоичная мутация | `binary_mutation` | Замена случайного гена (полигона) на новый случайный |
| Присоединение | `append_mutation` | Добавление нового случайного полигона в конец |
| Вставка | `insert_mutation` | Вставка нового полигона в случайную позицию |
| Удаление | `delete_mutation` | Удаление случайного полигона |
| Обмен | `swap_mutation` | Обмен местами случайного гена с соседом |

### Операторы отбора в новую популяцию

| Оператор | Функция | Описание |
|---|---|---|
| Вытеснение | `displacement_selection` | Все потомки образуют новое поколение |
| Элитарный | `elitist_selection` | Лучшие из объединения родителей и потомков |
| Равномерная замена | `uniform_random_replacement` | Случайные родители заменяются случайными потомками |

## Параметры запуска

| Параметр | По умолчанию | Описание |
|---|---|---|
| `Npop` | 20 | Размер популяции |
| `Ntri` | 100 | Количество полигонов на особь |
| `num_verts` | 3 | Количество вершин у полигона |
| `maxgen` | 500 | Максимальное число поколений |
| `pmut` | 0.15 | Вероятность мутации |
| `colour_init` | "random" | Начальный цвет полигонов ("random", "black", "white") |
| `alpha_init` | "random" | Начальная прозрачность ("random" или число 0-255) |
